# Support-Resistance-Trade-Analysis-Report

This documentation covers three sessions on identifying key price levels using TradingView. It starts with marking the support level on a Bitcoin (BTCUSD) 1-hour chart, followed by identifying the resistance level on a similar Bitcoin chart, and concludes with a support and resistance trade analysis on Ethereum (ETHUSD), where a long trade is executed near the support level and closed near resistance, resulting in a documented profit
